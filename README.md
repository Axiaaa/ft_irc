### ft_irc
# Overview
ft_irc is an IRC (Internet Relay Chat) server. The goal of the project was to create a working IRC server that handles communication between clients using the IRC protocol. Throughout the project, we focused on understanding networking concepts, handling concurrency with multiple clients, and implementing basic IRC features like channels, messages, and nicknames.

# Features
User authentication: Allows users to register and authenticate with the server.
Private messaging: Users can send direct messages to each other.
Channel management: Users can create, join, and leave channels.
Public messaging: Messages can be broadcast to all users within a channel.
Nickname management: Users can change their nickname during a session.
Server-client protocol: The server follows basic IRC protocol commands.
Some other commands: ``KICK``, ``MODE``, ``PING`` and more...
